Durante o desenvolvimento deste projeto, foram aplicados conhecimentos relacionados a:

Construção de simuladores no Excel;
Utilização de funções financeiras;
Cálculos de valor futuro;
Criação de cenários;
Estruturação de parâmetros de entrada;
Validação de dados;
Utilização de nomes definidos;
Organização de informações;
Visualização de dados por meio de gráficos;
Documentação de projetos técnicos;
Utilização do GitHub para apresentação do projeto.
